Tata Cara Menggunakan Gemini API Key

Panduan 4 langkah mudah dari Google AI Studio ke DayFlow

1
Buka Google AI Studio

Buka portal resmi Google AI Studio dan masuk menggunakan akun Google / Gmail Anda.

Buka Google AI Studio
2
Klik "Create API Key"

Klik tombol biru bertuliskan "Create API key". Pilih opsi default Create API key in default project (100% gratis tanpa kartu kredit).

3
Salin (Copy) Kunci API

Klik tombol Copy pada kunci yang muncul. Kunci API diawali dengan teks AQ..

4
Tempel ke Input DayFlow & Simpan

Tempelkan (paste) kode ke kolom Gemini API Key di bawah, tekan Uji Koneksi Key, lalu klik Simpan Pengaturan.
