Tata Cara Mendapatkan & Memasang Gemini API Key

Panduan langkah demi langkah untuk mendapatkan API Key gratis langsung dari Google AI Studio dan memasukkannya ke dalam aplikasi DayFlow agar seluruh fitur AI aktif.

Arsitektur AI Terpusat (Bebas Input Key Bagi Pengguna) DayFlow mendukung Serverless Gateway (Cloudflare Worker 100% gratis tanpa kartu kredit). Pengembang dapat menyimpan 1 API Key di serverless backend, sehingga seluruh pengguna umum dapat langsung menikmati asisten AI tanpa perlu memiliki atau memasukkan API Key sendiri.
100% Gratis & Bebas Biaya Google AI Studio menyediakan kuota gratis tanpa kartu kredit dengan batas 15 permintaan per menit (RPM), sangat memadai untuk jadwal harian pribadi.
Buka Google AI Studio
1

Kunjungi Google AI Studio

Buka situs resmi Google AI Studio pada peramban Anda. Masuk (Sign In) menggunakan akun Google / Gmail Anda.

Kunjungi aistudio.google.com/app/apikey
2

Klik Tombol "Create API Key"

Setelah masuk ke halaman API Keys, klik tombol biru bertuliskan "Create API key" (atau "Get API key").

Jika muncul pilihan project, pilih opsi default "Create API key in default project" atau pilih project Google Cloud yang Anda miliki.

3

Salin Kunci API (Copy)

Setelah proses pembuatan selesai, sebuah jendela akan menampilkan deretan karakter unik. Klik tombol Copy di samping kunci tersebut.

Format kunci API Google umumnya diawali dengan karakter:

AQ... (sekitar 39 karakter) Format resmi Google AI 2026
4

Tempelkan ke DayFlow & Simpan

Kembali ke aplikasi DayFlow, buka tab Setelan (Pengaturan).

Pada kartu Gemini API Key, tempelkan (paste) kode yang baru Anda salin ke dalam kolom input.

Klik tombol Uji Koneksi Key untuk memastikan status koneksi aktif, lalu tekan tombol Simpan Pengaturan di bagian bawah.

Pertanyaan Umum (FAQ)
Apakah API Key saya aman di DayFlow? Sangat aman. DayFlow beroperasi secara local-first. Kunci API Anda disimpan langsung di browser perangkat Anda (localStorage) dan hanya dikirimkan ke server resmi Google API (generativelanguage.googleapis.com) saat memproses permintaan AI. Tidak ada pihak ketiga yang memiliki akses ke kunci Anda.
Model Gemini apa saja yang didukung? DayFlow mendukung seluruh lini model mutakhir Gemini: Gemini 3.8 Flash (direkomendasikan), Gemini 3.5 Flash-Lite (hemat kuota), Gemini 3.6 Flash, dan Gemini 2.5 Flash. Anda dapat menggantinya kapan saja melalui menu Setelan.
Apa yang harus dilakukan jika muncul error kuota (Quota Exceeded)? Tunggu 1 hingga 2 menit agar batas RPM (Request Per Minute) Google ter-reset otomatis, atau pilih model Gemini 3.5 Flash-Lite di tab Pengaturan yang memiliki batas kuota lebih longgar.
Bagaimana cara menggunakan Groq di DayFlow? Buka menu Setelan > pilih tab Groq (LPU / xAI). Anda dapat memasukkan API Key pribadi dari GroqCloud (awalan gsk_) atau xAI (awalan xai-), ataupun menggunakan Serverless Gateway Cloudflare yang telah dikonfigurasi dengan environment variable GROQ_API_KEY.
